# Dropzone 🎯

A physics-powered name picker. Add names, give each one a color, then drop
marbles into a randomized pinball course and watch who tumbles out first.

## Features

- 🎨 Per-name color picker (auto-assigned, fully customizable)
- 👥 Up to 50 players per race
- 🎲 A brand-new, randomly generated pinball course every round — staggered
  peg rows, rotating spinners, and bouncy kicker bumpers
- ⏳ A locked gate above the finish line that only opens after 10 seconds,
  so the course length/sparsity can never make the race too short
- 🏆 Podium + full ranked results with confetti and a sequential reveal
- 📱 Responsive — plays well on both desktop and mobile
- 💾 Player list is remembered locally between visits (no backend, no accounts)
- 🔊 Optional sound cues (mute toggle in the top-right corner)

## Getting started

```bash
npm install
npm run dev       # local dev server
npm run build      # production build -> dist/
npm run preview    # preview the production build locally
```
